- **[ARCHITECTURE.md](file:///c:/Users/Arif/Desktop/EkimMemoOrtak/ARCHITECTURE.md):** Projenin canlı güncellenen görsel mimari ve akış şemaları (Mermaid).
- **[TECHNICAL_DOC.md](file:///c:/Users/Arif/Desktop/EkimMemoOrtak/TECHNICAL_DOC.md):** Dizin yapısı, veritabanı yolları ve teknik açıklamalar.
